# מעטפת אנדרואיד - חבילת מדידות

פרויקט Android Studio (Kotlin) שעוטף את אפליקציית המדידות (`app/src/main/assets/www/`) בתוך WebView.

**התיקון המרכזי בפרויקט הזה:** אין כאן שום Foreground Service ואין שום Notification קבועה כשהמטר מחובר. החיבור לבלוטות' (`MeterBridge.kt`) חי רק כל עוד האפליקציה פתוחה על המסך, ומתנתק לבד כשסוגרים אותה - בדיוק כמו אפליקציה שלא מריצה שירות רקע. כך לא מופיעה שום התראה עם שם/מספר סידורי של המטר.

## איך מקבלים APK מוכן - בלי להתקין שום דבר

1. פותחים חשבון GitHub חינמי (אם אין עדיין): github.com -> Sign up.
2. יוצרים Repository חדש וריק (New repository), שם כלשהו, Private או Public - לא משנה.
3. בעמוד הריפוזיטורי לוחצים "Add file" -> "Upload files", וגוררים לתוכו **את כל התוכן של התיקייה הזו** (את כל הקבצים והתיקיות שבפנים, לא את התיקייה עצמה בתור קובץ אחד). מאשרים commit.
4. עוברים ללשונית "Actions" למעלה בעמוד הריפוזיטורי. אחרי כמה שניות אמורה להופיע ריצה בשם "Build APK" (אם לא - יש כפתור "Run workflow" בלשונית Actions, לוחצים עליו).
5. מחכים כ-3 עד 6 דקות עד שהריצה מסומנת בעיגול ירוק.
6. לוחצים על הריצה שהסתיימה, גוללים למטה ל"Artifacts", ומורידים את `measure-app-debug-apk` (קובץ zip קטן שמכיל בתוכו את ה-APK).
7. מעבירים את ה-APK לטלפון (למשל דרך הורדה ישירה בטלפון, או שליחה לעצמך) ומתקינים (יידרש לאשר "התקנה ממקורות לא ידועים" בפעם הראשונה - זה תקין, זו לא אפליקציה מחנות Play).

## מה לעשות אם הבנייה נכשלת (הריצה מסומנת באדום)

לוחצים על הריצה האדומה, פותחים את הצעד שנכשל, ומעתיקים את השורות האחרונות (השגיאה) - אפשר להדביק אותן בצ'אט ואני אתקן.

## מבנה

- `app/src/main/assets/www/` - אותם קבצי אתר בדיוק כמו בגרסת הדפדפן/PWA.
- `app/src/main/java/com/timbercww/measure/MainActivity.kt` - חלון ה-WebView, טעינת האתר, הרשאות.
- `app/src/main/java/com/timbercww/measure/WebBridge.kt` - הפונקציות שנחשפות ל-JS בתור `window.Android.*`.
- `app/src/main/java/com/timbercww/measure/MeterBridge.kt` - חיבור הבלוטות' למטר הלייזר (התיקון המרכזי).
- `.github/workflows/build.yml` - ההגדרה שגורמת ל-GitHub לבנות APK אוטומטית בכל העלאה.
